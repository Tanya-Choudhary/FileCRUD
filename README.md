# FileCRUD Application 📁

A Python-based file handling application with support for both **Streamlit** (Web UI) and **Tkinter** (Desktop GUI). This project allows users to perform CRUD (Create, Read, Update, Delete) operations on text files seamlessly.

---

## 🚀 Features

- **Create File**: Easily create new text files and write initial content.
- **Read File**: View the contents of existing files.
- **Update File**: Append or edit existing file content.
- **Delete File**: Remove files safely from the directory.
- **Dual Interface**:
  - 🌐 **Web Interface**: Powered by Streamlit for modern browser access.
  - 🖥️ **Desktop GUI**: Built with Tkinter for local desktop use.
